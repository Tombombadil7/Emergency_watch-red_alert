# Emergency Alert Watch (שעון התרעה למצבי חירום)

## תיאור הפרויקט
נסיום חובבני ליצירת פרוייקט חומרתי-תוכנתי למתן מענה להתרעה אזעקות לאוכלוסיות שלא מקבלות מענה כיום (בפרט קשישים ולקויי שמיעה) בהתראה והתראה מוקדמת לאירועי חירום של פיקוד העורף. המערכת מתוכננת לתפקד כצמיד חכם חסכנוי בסוללה שייתן חיווי חזותי ובעיקר חיווי רטט משמעותי.
המערכת מתוכננת תחת עקרונות נוחות משמתמש מקסימלית והעדר "חיכוך" בהפעלה (כמעט ללא צורך בהגדרה מראש ושליטה מרוחקת מרכזית - חיסכון משמעותי בסוללה וכו) , התרעה משמעותית ברגע האמת ומחיר ייצור נמוך.

המערכת פועלת כולה על גבי הרשת הסלולרית (ללא WiFi) ומתוכננת לתמוך ב:
- עדכון התרעה מקדימה והתרעת אמת מבוססת sms (לזמינות מרבית גם במיעוט קליטה)
- עדכון פוליגונים ותוכנה מרוחק בעת הצורך.
- אבטחה קריפטוגרפית משמעותית (אימות הודעות חירום באמצעות הצפנת מפתח ציבורי **ECDSA P-256**).
- הצגת נתונים על גבי מסך עגול המבוסס דרייבר **GC9A01** (באמצעות ספריית `TFT_eSPI`).
